## Why

The v2.15 README has a polished English landing page and one Chinese summary, but Chinese readers still need to translate the main installation, safety, compatibility, and governance sections. A public open-source project should make its primary evaluation and onboarding path available in both languages.

## What changes

- Convert the main README sections into paired English/Chinese headings and content blocks.
- Keep commands, file paths, version pins, links, and safety terminology identical in meaning across both languages.
- Preserve the concise English project description and existing badges while making the rest of the visitor journey bilingual.
- Replace the end-only Chinese summary with distributed Chinese guidance next to each corresponding English section.

## Capabilities

### New Capabilities

- `bilingual-readme`: bilingual public-facing README guidance for evaluating, installing, operating, and contributing to RepoAtlas.

## Impact

- Affected files: `README.md` and this OpenSpec change.
- No package metadata, runtime behavior, Harness action schema, session-only state, release process, npm posture, or compatibility contract changes.
- No tag, GitHub Release, npm publication, network access, dependency installation, or source workspace mutation from the feature.

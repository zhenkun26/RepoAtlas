# v2.14 public release preflight

This change prepares the first source-first public release of RepoAtlas. It adds support/release guidance and a read-only, fail-closed candidate preflight. It does not create tags, GitHub Releases, npm publications, deployment, or remote writes.

The preflight is allowed to report `blocked` while the named copyright holder, release notes, or other human release decisions remain open. A `ready` observation is only a local candidate fact; the actual release still requires a separately authorized manual action.

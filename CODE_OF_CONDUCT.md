# Code of Conduct

## Our standard

We want RepoAtlas to be a welcoming, technically rigorous project. Participants must be respectful, constructive, and clear. Harassment, discrimination, threats, personal attacks, sexualized conduct, doxxing, deliberate disruption, and publishing private information without consent are not acceptable.

Technical disagreement is welcome when it focuses on evidence, constraints, and the work. It is not acceptable to pressure contributors into bypassing safety boundaries, review gates, or explicit authorization.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this code, and may temporarily or permanently restrict participation when necessary to protect the community. They will aim to explain decisions and handle reports confidentially.

To report a conduct concern, use the private security/reporting channel described in [SECURITY.md](SECURITY.md) or contact the repository maintainers privately. Do not open a public issue containing personal information or an unpatched security concern.

This code applies in project spaces and whenever someone is representing the project publicly.
